# Peace — MBTI Personality Game

An interactive MBTI personality game built with Next.js.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- MBTI-based personality quiz gameplay
- Character selection with multiple layouts
- Embeddable flow designs
- PWA support

## Deploy

Deployed on [Vercel](https://vercel.com) as the **peace** project.
